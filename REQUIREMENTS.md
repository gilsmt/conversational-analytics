# Requirements

The behavioural spec this implementation was built against. It documents the
observable contract of the app — import rules, analysis semantics, chat scoping,
and frontend surface — rather than the requirements of any particular brief.

For setup and usage, see [README.md](README.md).

## Backend

- FastAPI app lives under `packages/server/app` with entrypoint `app.main:app`.
- SQLAlchemy ORM models live in `packages/server/models`.
- Routes are versioned under `/api/v1`.
- PostgreSQL is required through `DATABASE_URL`; Gemini is required through
  `GEMINI_API_KEY`; `GEMINI_MODEL` defaults to `gemini-2.5-flash`.
- Commands from `packages/server`:
  - `uv run task api`
  - `uv run task db_migrate`
  - `uv run task seed`
- Alembic migrations live in `packages/server/migrations`.
- No authentication, users, workspaces, or datasets.

## Import

- `uv run task seed` imports `../../Conversations/` by default and accepts
  `--source` for a folder or zip.
- `POST /api/v1/conversations/import` accepts one zip or folder-selected CSV
  files via multipart form data.
- Imports skip duplicate `session_id` values without modifying existing data.
- Malformed transcript files fail individually; valid files in the same batch
  may still import.
- Imported message IDs are generated by the database; source CSV message IDs are
  discarded.

## Analysis

- Insights and qualifying questions are managed by CRUD APIs.
- Definition deletes are hard deletes and remove related JSONB result keys.
- Definition edits/toggles mark affected conversations pending.
- Analysis runs are in-process background tasks with progress in
  `analysis_runs`.
- Default analysis processes pending/failed conversations; re-run all is an
  explicit option.
- Analysis is sequential, retries transient Gemini failures twice, and supports
  cooperative cancellation after the current conversation.
- Insight results are `{ value, explanation }`; qualifying answers are strings
  or null.

## Chat

- Chat threads are global and persistent.
- Scope is `all` or `single`; single threads require `conversation_id`.
- New Session and conversation clicks create empty threads immediately.
- Chat messages store role plus text content.
- `POST /api/v1/chat/threads/{id}/messages` streams SSE events:
  `token`, `status`, `error`, `done`.
- Stopping a stream aborts the request; only the user message is persisted.
- Gemini tools are read-only and server-internal.

## Frontend

- Next.js frontend uses SWR for REST data and cache revalidation.
- `NEXT_PUBLIC_API_URL` defaults to `http://127.0.0.1:8000`.
- `/` is a permanent import/start screen.
- `/dashboard` shows status counts, Recharts bar charts, summaries, and
  conversation rows.
- `/chat/new` creates an all-scope empty thread and redirects to `/chat/{id}`.
- `/chat/{id}` supports scoped chat, streaming, stop, and single-conversation
  transcript panel.
- Left sidebar lists Dashboard, New Session, Conversations, and Chats.
- Right floating sidebar manages imports, analysis runs, insights, and
  qualifying questions.

## Verification

- Do not add automated tests.
- Run backend migrations, seed, Ruff, client lint, and client type-check.
- Manually verify import, CRUD, analysis run/cancel, dashboard, both chat
  scopes, stop behavior, rename/delete, and conversation cascade delete.
